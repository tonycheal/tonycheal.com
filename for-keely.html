Design Resources

♠

A starter pack for Keely (and the girls) — where to go for fonts, colour, icons, and inspiration. The web has moved on a fair bit since we last did this in earnest. Hopefully this helps you skip the "what does everyone use now?" stage.

Type & Fonts

  • Google Fonts — Still the easy default. Much improved: supports variable fonts, previews in context, decent search.
  • Fontshare — Indian Type Foundry's free quality library. What a lot of working designers reach for now — feels less "stock" than Google Fonts.
  • Bunny Fonts — Privacy-respecting drop-in mirror of Google Fonts. Same fonts, no Google tracking. Use the same names as Google Fonts.
  • Velvetyne — Indie/experimental free fonts. Characterful and a bit weird in the best way.
  • Pangram Pangram — Modern foundry; mix of free and paid. Lovely contemporary work.
  • Wordmark.it — Paste your text, see it rendered in every font you have installed. Saves a lot of clicking.

Colour

  • Realtime Colors — Live-preview a palette applied to a real example site. The single best way to gut-check a colour scheme.
  • Coolors — Palette generator and huge searchable library. The standard.
  • Color Hunt — Curated daily palette feed; good for browsing.

Icons

  • Phosphor Icons — Six weights, broad coverage. Current go-to for most projects.
  • Lucide — Minimal line icons; the well-maintained fork of Feather.

Inspiration

  • Land Book — Curated showcase of clean, modern sites. Heavy on contemporary product/agency work.
  • SiteInspire — Broader showcase, well-tagged. Around for years and still good.
  • Are.na — Quiet alternative to Pinterest; designers' moodboarding tool of choice. Less algorithmic, more considered.
  • Fonts in Use — Real-world examples of typefaces in context. Once you've shortlisted a font, see who else has used it and how.

Photographer Portfolios

For Sapphire, if she ever wants a turnkey hosted option rather than rolling her own:

  • Format — Photographer-focused, clean themes.
  • Cargo — Designer-favourite, more flexible and creative.
  • Pixieset & Pic-Time — Client galleries (delivery, proofing). Different category, also useful for working photographers.
  • Squarespace — No-code, works fine if speed-to-launch matters more than craft.

Markdown / Blogging

A modern way to run a blog or "digital garden" — write in Markdown (in Obsidian, iA Writer, or anything plain-text) and publish to the web. Several routes:

  • Astro — Modern static site generator, very popular for content sites. Theme gallery at themes.astro.build. Build runs locally; deploy the output to Cloudflare Pages/Workers — same plumbing we just set up.
  • Obsidian Publish — Official paid service (~$8/month); hit "publish" from inside Obsidian. The lowest-friction path if you're already an Obsidian user.
  • Quartz — Free open-source alternative. Builds an Obsidian vault into a static site. Maggie Appleton's site runs on Quartz. More setup, more design control.
  • Bear Blog — Minimal hosted Markdown blogging. Sign up, start writing. Free. Good when you want zero plumbing.
  • Ghost — Beefier hosted platform (~$9/month). Worth knowing about if Bear feels too sparse.

General

  • Figma — Design tool. Now the industry standard, runs in the browser, free tier is generous.
  • Practical Typography — Butterick's free book. Typography first principles, clear and opinionated. Worth an evening.
  • CodePen — Sandbox for quick HTML/CSS experiments without a project.

This is a "where to start" not a "where to stop". Each link leads to a dozen more if you follow the breadcrumbs. Add to it as you find better.
